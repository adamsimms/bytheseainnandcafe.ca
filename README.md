# By The Sea Inn & Café

Squarespace site for [bytheseainnandcafe.ca](https://bytheseainnandcafe.ca/), an inn and café on the Green Bay shoreline in King's Point, Newfoundland.

This repo tracks **site customizations you can version outside the CMS**. Page content, images, menus, and Style Editor tweaks live in Squarespace.

## Custom CSS

As of the initial repo setup, the live site has **no published Custom CSS**. `custom.css` in this repo is a stub ready for overrides.

1. Edit `custom.css` in this repo.
2. Copy the rules into Squarespace → **Design → Custom CSS**.
3. Save and verify on [bytheseainnandcafe.ca](https://bytheseainnandcafe.ca/).

## What is not in this repo

- CMS pages, collections, and uploaded media
- Style Editor / theme tweaks (colors, fonts, spacing)
- Code Injection (header/footer) unless you add files here later
- Commerce products, orders, and bookings data
